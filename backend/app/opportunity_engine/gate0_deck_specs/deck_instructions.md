# Gate 0 Leadership Deck Instructions

## Purpose

This deck supports Manny's Gate 0 leadership review. It helps leadership decide whether a category opportunity should move into PRD/RFQ work.

This is not a PO approval deck. Do not present vendor cost, MOQ, samples, EVT, PI, or final order quantity as approved unless those later-stage artifacts already exist.

## Source Policy

The deck must use only the current Ideation Development outputs:

- Step 1 gap workbook
- Step 2 ideation workbook
- Step 3 research workbook, when available

Do not read legacy Claude Workbook source folders, old Helium10 folders, old line-review workbooks, or manual research files as live source data for this deck.

## Visual Contract

Use the team review deck style shown in `Line Strategy March '26 Review 2.pptx`:

- 13.333 x 7.5 widescreen canvas
- teal top rule
- large dark title
- teal underlined section headers
- dense white canvas, not dashboard cards
- teal table headers
- alternating pale table rows
- compact source footnote
- pale footer band with Sunco mark at bottom right

## Deck Order

1. Category research snapshot
2. Current Sunco line review
3. Ideation introduction / opportunity shortlist
4. One product opportunity slide per Step 2 ideation row
5. Gate 0 decision slide

## Editable Spec Files

Each slide type has its own markdown file so that changes can be scoped:

- `slides/01_category_research_snapshot.md`
- `slides/02_current_line_review.md`
- `slides/03_ideation_introduction.md`
- `slides/04_product_opportunity.md`
- `slides/05_gate0_decision.md`

Change the slide-specific file when the requested change affects only one slide type. Change this deck-level file only for source policy, deck order, or style-wide rules.

## Per-Run Audit

Every generated deck package includes a snapshot of this folder under `markdown_specs`. That snapshot records which version of the instructions existed when the deck was generated.
