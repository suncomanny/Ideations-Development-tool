# Final Slide - Gate 0 Decision

## Role

End with a clean leadership decision frame.

This slide answers: "Should we move this opportunity into PRD/RFQ work?"

## Layout

Use the same team deck style:

- Top teal rule
- Centered title
- Left section for decision logic
- Right section for next steps if approved
- Optional decision table below
- Source footnote
- Sunco footer

## Decision Options

Use three simple outcomes:

- Pursue
- Hold
- Needs More Data

## Recommended Next Step If Approved

- Create PRD/RFQ package for selected rows
- Coordinate pack-size research with the data team
- Request vendor quote/sample evidence later in the process

## Guardrails

This is not a PO approval. Do not mention final order quantity, MOQ approval, PI approval, or production release as the next decision.
