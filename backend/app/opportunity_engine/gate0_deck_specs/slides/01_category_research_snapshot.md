# Slide 1 - Category Research Snapshot

## Role

Open the deck with category opportunity context. This slide answers: "Why is this category worth discussing now?"

## Inputs

- Step 1 gap workbook summary and source/audit rows
- Step 2 row count
- Step 3 matched research row count
- Existing line-review row count
- Any category-level demand signal already present in the current outputs

## Layout

Use the team deck research snapshot pattern:

- Top teal rule
- Title at upper left
- Subtitle directly below title
- Left column for evidence base and workflow counts
- Right column for product segment priorities and top opportunities
- Small stat callouts near the lower right
- Source footnote above footer
- Sunco footer at bottom right

## Required Content

- Latest Step 1 workbook name
- Number of Step 2 ideation rows
- Number of Step 3 analyzed rows matched
- Number of current line-review rows included
- Top 3-5 opportunities from Step 2
- One concise recommended Gate 0 action

## Tone

Use category-pursuit language. Do not use PO approval language.

Good:

- "Use this deck to align on which opportunities deserve PRD/RFQ work."
- "Review row-level evidence before approval."

Avoid:

- "Approve PO quantity."
- "Ready to order."
- "Vendor has been selected."
