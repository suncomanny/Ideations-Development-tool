# Slide 3 - Ideation Introduction / Opportunity Shortlist

## Role

Summarize the candidate ideations before the detailed product slides.

This slide answers: "What are we considering, and which rows need leadership attention?"

## Inputs

- Step 2 ideation workbook rows
- Step 3 summary sheet, when available
- Step 1 source mapping and selection rationale

## Layout

Use the original line summary pattern:

- Top teal rule
- Centered title
- Stats stack on the left
- Opportunity comparison table on the right
- Teal table title strip
- Teal table header row
- Alternating pale rows
- Sunco footer

## Required Stats

- Step 2 Rows
- Step 3 Matched
- Current Line Rows
- Favorable Reads

## Table Columns

- Ideation
- Strategy
- Key Spec
- Outlook
- Confidence
- Next Step

## Row Limit

Show the first 10 rows on this slide. Detailed rows continue as individual product slides.

## Guardrails

- Keep visible text short.
- Use speaker notes or backend audit JSON for long evidence strings.
- Do not let long Step 2 ideation names control the entire slide. Use a shortened display title when needed.
